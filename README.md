# 🍽️ The Crave Craft

**Crafted like art, served with love. ❤️**

A beautifully designed, responsive landing page for **The Crave Craft**, a cloud kitchen focused on bringing delicious food and delightful experiences to every table.

Built using **HTML5, CSS3, and Vanilla JavaScript**, the website features a warm, brand-inspired design, interactive food menu, smooth animations, and a mobile-friendly experience.

---

## 🌐 Overview

The Crave Craft website serves as the brand's digital storefront, providing customers with a simple and engaging way to discover the kitchen, explore its menu, and connect with us through Instagram.

The website is designed to be linked directly from the brand's Instagram profile.

## ✨ Features

- **Brand-focused landing page** – Warm, welcoming introduction to The Crave Craft.
- **Custom branding** – Incorporates the official logo and brand-inspired color palette.
- **Interactive food menu** – Displays menu items with descriptions, pricing, and nutritional information.
- **Category-wise navigation** – Browse menu items by food category.
- **Menu search** – Quickly find specific dishes.
- **Smooth animations** – Subtle scroll animations and interactive transitions.
- **Responsive design** – Optimized for desktops, tablets, and mobile devices.
- **Instagram integration** – Direct access to The Crave Craft's Instagram profile.
- **Lightweight implementation** – No heavy frameworks or unnecessary dependencies.

## 🚀 Getting Started

You can run the website locally without installing any dependencies.

### 1. Clone the repository

```bash
git clone <YOUR_REPOSITORY_URL>
```

### 2. Navigate to the project directory

```bash
cd <REPOSITORY_NAME>
```

### 3. Launch the website

Open `index.html` directly in your browser.

Alternatively, use the Live Server extension in VS Code for local development.

## 🍔 Menu Management

Menu information is maintained separately in `menu-data.js`, making it easy to update dishes without modifying the website structure.

Each menu item can include:

- Item name
- Description
- Category
- Carbohydrate content
- Protein content
- Swiggy/Zomato price

The initial menu selection is based on the **Pre Menu** sheet, with corresponding item details sourced from the **TCCM** sheet.

## 🎨 Design Philosophy

The visual identity of The Crave Craft is built around three key elements:

- **Warmth:** Cream and earthy backgrounds that create a welcoming atmosphere.
- **Craftsmanship:** Elegant typography and thoughtful visual details.
- **Freshness:** Natural green accents balanced with rich chocolate-brown tones.

The overall experience aims to reflect the brand's tagline:

*Crafted like art, served with love.*

## ☁️ Deployment

The website is designed for static hosting and can be deployed directly through Netlify.

### Netlify deployment

1. Push the project to GitHub.
2. Log in to [Netlify](https://www.netlify.com/).
3. Import the GitHub repository.
4. Configure the deployment settings:
   - Build command: Leave empty.
   - Publish directory: `.` (project root).
5. Deploy the website.

A custom domain can subsequently be configured through your domain provider.
